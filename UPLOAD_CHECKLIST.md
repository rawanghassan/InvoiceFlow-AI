# Public GitHub Upload Checklist

Before uploading this folder to a public repository:

- [ ] Confirm no webhook URLs, tokens, chat IDs, credentials, or account identifiers are present.
- [ ] Confirm no production ledger exports, invoice datasets, notebook state files, or `.pbix` files were added.
- [ ] Confirm source-code folders contain documentation only and not private implementation files.
- [ ] Confirm concept visuals do not expose private production data.
- [ ] Keep the repository license and security notes in place.
- [ ] Maintain the private implementation separately from this portfolio repository.
